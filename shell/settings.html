Instances

The persea servers this app connects to. Each instance keeps its own login, sessions and settings in a separate data store, so signing in to one never touches another.

Appearance

Shell theme. Each server keeps its own web theme inside the window; this only affects the app's own pages.

Performance

Hardware acceleration for the app's windows. Turn it off when a GPU driver renders blank or glitchy windows; the app falls back to software rendering.

On by default. The change applies after the next launch.

Network

Allow servers whose TLS certificate is not trusted by this system: self-signed certificates and private CAs you have not installed in the OS trust store. Certificate validation is skipped for every server window while this is on, so only enable it for servers you control.

Off by default. Takes effect immediately on Linux; on Windows after the next launch. Not available on macOS, where the server certificate must be trusted by the system. A single server can opt out individually in its Add/Edit dialog, but that applies to the connection check only: the web engines cannot skip validation per origin, so the windows always follow this global toggle.

Shortcuts

Global chords that fire while the app runs in the background. Write them as modifiers plus a key, e.g. ctrl+alt+p. A chord that the OS or another program already owns shows as a conflict and stays inactive until you pick a different one.

Notifications

Session alerts while the app runs in the background.

Quiet by default: session ended, errors, transfer complete and update available. First enable sends a test notification.

Kiosk

Locks this window to a single server: fullscreen, close blocked, only that server's pages reachable. The toggle appears only for servers whose probe reports kiosk support. Entering kiosk takes the window to the server's connections page; leave with Ctrl+Alt+Shift+Q pressed twice.

Updates

Application updates and the update channel.

Version

Channel: stable. Install a beta build to follow the beta channel; beta installers never consume the stable channel.
