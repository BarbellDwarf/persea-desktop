Instances

The persea servers this app connects to. Each instance keeps its own login, sessions and settings in a separate data store, so signing in to one never touches another.

Appearance

Shell theme. Each server keeps its own web theme inside the window; this only affects the app's own pages.

Appearance

Performance

Hardware acceleration for the app's windows. Turn it off when a GPU driver renders blank or glitchy windows; the app falls back to software rendering.

On by default. The change applies after the next launch.

Shortcuts

Global chords that fire while the app runs in the background. Write them as modifiers plus a key, e.g. ctrl+alt+p. A chord that the OS or another program already owns shows as a conflict and stays inactive until you pick a different one.

Notifications

Session alerts while the app runs in the background.

Quiet by default: session ended, errors, transfer complete and update available. First enable sends a test notification.

Kiosk

Locks the window to a single instance. The kiosk option appears only for servers whose probe reports kiosk support.

Kiosk mode arrives in a later release (D12).

Placeholder field that exercises the shell clipboard path; the pairing flow itself arrives in a later release (D07).

Updates

Application updates and the update channel.

Automatic updates arrive in a later release (D13).
