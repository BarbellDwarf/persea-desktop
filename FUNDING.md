# Funding

Persea Desktop is part of the persea project. The desktop client is free and open source (Apache-2.0), and its development is funded by the community through the [persea Open Collective](https://opencollective.com/persea).

What contributions pay for:

- **CI infrastructure** for the Windows, Linux, and macOS build matrix
- **Code-signing certificates** (Windows SmartScreen, macOS notarization) so installers stop warning users
- **Test machines** for the per-engine matrix (WebView2, WebKitGTK, WKWebView)
- **Design work** (icons, installer art, documentation)

See the [persea collective](https://opencollective.com/persea) for the full picture, or sponsor the project directly: https://opencollective.com/persea
