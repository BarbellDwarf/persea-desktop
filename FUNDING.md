# Funding

Persea Desktop is part of the persea project. The desktop client is free and open source (Apache-2.0), and its development is supported by the community through [GitHub Sponsors](https://github.com/sponsors/barbelldwarf) and [Ko-Fi](https://ko-fi.com/barbelldwarf).

What contributions pay for:

- **CI infrastructure** for the Windows, Linux, and macOS build matrix
- **Code-signing certificates** (Windows SmartScreen, macOS notarization) so installers stop warning users
- **Test machines** for the per-engine matrix (WebView2, WebKitGTK, WKWebView)
- **Design work** (icons, installer art, documentation)

Support the project on [GitHub Sponsors](https://github.com/sponsors/barbelldwarf) or [Ko-Fi](https://ko-fi.com/barbelldwarf).
